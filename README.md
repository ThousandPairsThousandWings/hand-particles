# 手势粒子动画 - Hand Particles

一个纯浏览器端的摄像头手势交互项目：打开网页、授权摄像头，即可用手势操控屏幕上的 3D 粒子动画。单 HTML 文件、零构建、本地运行。

![技术栈](https://img.shields.io/badge/HTML5-Canvas_2D-blue) ![依赖](https://img.shields.io/badge/MediaPipe-Hands-green) ![许可](https://img.shields.io/badge/%E6%9E%84%E5%BB%BA-%E6%97%A0-lightgrey)

## 功能特性

- **六种粒子动画**：球体、光环、螺旋、波场、星座、星图，随时切换
- **四种手势交互**：无需任何设备，一块摄像头 + 一只手即可操控
- **本地隐私安全**：画面仅在浏览器内处理，不上传任何数据
- **流畅性能**：轻量追踪模型 + 预渲染光晕精灵 + 手写 3D 透视投影

## 快速开始

1. 下载本仓库，双击打开 `hand-particles.html`（Chrome / Edge）
2. 在浏览器弹窗中允许使用摄像头
3. 将手掌对准摄像头，即可开始互动

> 若浏览器因安全策略阻止本地文件调用摄像头，可使用任意静态服务器（如 `npx serve` 或 VS Code Live Server）在 `localhost` 下打开。

## 手势说明

| 手势 | 效果 |
|---|---|
| **攥拳 / 张开** | 连续缩放粒子（约 0.15x → 2.0x） |
| **捏合拖动** | 旋转视角、平移画面中心，松手后保持当前视角 |
| **左右摇晃** | 切换到下一种粒子动画（约 0.9 秒窗口内两次方向反转即触发，冷却 600ms） |
| **手离开画面** | 粒子缓慢恢复默认大小与位置 |

也可以通过右下角的选择器直接点选动画。

## 技术实现

- **MediaPipe Hands**（CDN 加载）：实时识别 21 个手部关键点，使用 `modelComplexity: 0` 轻量模型降低延迟
- **手势识别（纯几何逻辑）**：
  - 攥拳/张开 —— 指尖到手腕平均距离 ÷ 手掌参考尺寸，连续映射为缩放系数
  - 捏合 —— 拇指-食指距离 ÷ 手掌尺寸，带滞回阈值防抖
  - 摇晃 —— 手掌中心 X 坐标历史窗口内的方向反转计数
- **渲染（原生 Canvas 2D）**：
  - 预渲染径向渐变光晕精灵，全场景粒子复用
  - `globalCompositeOperation: lighter` 叠加发光
  - 手写 3D → 2D 透视投影（绕 Y 轴自转 + 固定倾角）
  - 摄像头画面半透明镜像叠加作为背景
- **主循环**：`requestAnimationFrame` 驱动，所有状态用 lerp 平滑插值
